# WaterCheck

軽井沢別荘 水抜きチェックアプリ

---

## 概要

WaterCheckは、軽井沢別荘の水抜き作業を確実に実施するためのチェックアプリです。

チェックリストによる作業管理、写真による作業証跡保存、メモ記録、バックアップ・復元機能に対応しています。

---

# 開発方針

## Phase1（Ver1.x～Ver2.x）

実際に使用できることを最優先とする。

- 必要な機能を段階的に実装する
- 安定動作を最優先とする
- 大規模なリファクタリングは行わない
- 将来の拡張（年度管理・家族共有・Evidence）を考慮した設計とする

## Phase2（Ver3.0）

完全版を目指す。

- リファクタリング
- ファイル構成整理
- DB設計整理
- コード最適化
- 保守性向上

# Ver1.0.08 実装内容

## チェック管理

- 水抜き項目チェック
- 完了状態管理
- 進捗表示
- LocalStorage保存

## 写真管理

- カメラ撮影
- 写真表示
- 写真拡大表示
- 写真撮り直し
- 写真削除

写真データはIndexedDBに保存します。

## メモ管理

- 作業メモ保存
- 自動保存対応

## バックアップ・復元

JSON形式によるバックアップに対応。

保存内容：

- チェック状態
- メモ
- 写真データ（Base64）
- バックアップ日時

復元処理：

JSON
↓
Base64写真変換
↓
Blob変換
↓
IndexedDB保存
↓
写真復元

## PWA対応

- ホーム画面追加対応
- Service Workerによるキャッシュ対応
- オフライン利用を考慮した設計
