# WaterCheck

軽井沢別荘 水抜きチェックアプリ

## 開発方針

### Phase1（Ver1.x～Ver2.x）

実際に使用できることを最優先とする。

- 必要な機能をすべて実装する
- 安定動作を最優先とする
- 大規模なリファクタリングは行わない
- 将来の拡張（年度管理・家族共有・Evidence）を考慮した設計とする

### Phase2（Ver3.0）

完全版を目指す。

- リファクタリング
- ファイル構成整理
- DB設計整理
- コード最適化
- 保守性向上
